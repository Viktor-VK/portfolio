# Портфолио аналитика данных

Проекты, показывающие реальный рабочий код по классификации, кластеризации, скорингу и построению
аналитических пайплайнов - от SQL и обработки данных до готовых решений и дашбордов. Каждый проект - в
своей папке, со своим README (задача, что делает решение, где эффект) и пронумерованными ноутбуками
пайплайна.

## Проекты

| Проект | Про что |
|---|---|
| [`Кластеризация точек продаж`](Кластеризация%20точек%20продаж) | Сегментация тысяч точек продаж по цене, размеру и ассортиментному профилю для решений по закупкам и ассортименту. [Страница с графиками](https://viktor-vk.github.io/projects/store-clustering/) |
| [`Скоринг и выбор ассортиментной матрицы`](Скоринг%20и%20выбор%20ассортиментной%20матрицы) | Score товара, отбор по шкале строгости и выбор итоговой товарной матрицы по сегменту - продолжение проекта выше. [Страница с графиками](https://viktor-vk.github.io/projects/assortment-matrix/) |
| [`Сквозной анализ цепи поставок`](Сквозной%20анализ%20цепи%20поставок) | Движение товара от поставщика через склады до магазинов по дням и причина каждого дня дефицита: поставщик, закуп или распределение. [Страница с графиками](https://viktor-vk.github.io/projects/supply-chain/) |
| [`synthetic_data`](synthetic_data) | Общая база синтетических данных (DuckDB) и её генератор - на ней выполняются проекты кластеризации, скоринга и цепи поставок |
| [`Мониторинг рынка вакансий hh.ru`](Мониторинг%20рынка%20вакансий%20hh.ru) | Работающий инструмент: парсер + дашборд для отслеживания рынка труда аналитиков |
| [`Сравнение рейтингов Tesera и BGG`](Сравнение%20рейтингов%20Tesera%20и%20BGG) | Мини-исследование на открытых данных: чем оценки настольных игр на Tesera отличаются от BoardGameGeek и почему «свой» топ всегда выглядит щедрее. [Страница с графиками](https://viktor-vk.github.io/projects/tesera-bgg/) |

## Что осознанно не включено

- Подключения к корпоративным БД, хосты, имена внутренних серверов и схем - убраны, запросы идут к локальной базе с синтетикой.
- Файлы с реальными данными (выгрузки, реестры точек, результаты расчётов) - не публикуются.
- Названия брендов, регионов и других идентифицирующих сущностей - обезличены.
- Поэтому проекты кластеризации, скоринга и цепи поставок выполняются на **синтетических данных** из общей базы
  [`synthetic_data`](synthetic_data): SQL-запросы и алгоритмы - как в рабочих расчётах, а данные сгенерированы
  (справочник лекарств - из открытого реестра ЖНВЛП). Цифры в этих ноутбуках не отражают реальный бизнес.
  `Мониторинг рынка вакансий hh.ru` и `Сравнение рейтингов Tesera и BGG` работают на публичных данных.
