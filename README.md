# Портфолио аналитика данных

Проекты, показывающие реальный рабочий код по классификации, кластеризации, скорингу и построению
аналитических пайплайнов - от SQL и обработки данных до готовых решений и дашбордов. Каждый проект - в
своей папке, со своим README (задача, что делает решение, где эффект) и пронумерованными ноутбуками
пайплайна.

## Проекты

| Проект | Про что |
|---|---|
| [`Кластеризация точек продаж`](Кластеризация%20точек%20продаж) | Сегментация тысяч точек продаж по цене, размеру и ассортиментному профилю для решений по закупкам и ассортименту |
| [`Скоринг и выбор ассортиментной матрицы`](Скоринг%20и%20выбор%20ассортиментной%20матрицы) | Score товара, ABC-классификация и выбор итоговой товарной матрицы по сегменту - продолжение проекта выше |
| [`Восстановление истории остатков`](Восстановление%20истории%20остатков) | Восстановление ежедневной истории остатков по точкам из текущего остатка и журнала движений |
| [`Мониторинг рынка вакансий hh.ru`](Мониторинг%20рынка%20вакансий%20hh.ru) | Работающий инструмент: парсер + дашборд для отслеживания рынка труда аналитиков |
| [`Сравнение рейтингов Tesera и BGG`](Сравнение%20рейтингов%20Tesera%20и%20BGG) | Мини-исследование на открытых данных: чем оценки настольных игр на Tesera отличаются от BoardGameGeek и почему «свой» топ всегда выглядит щедрее. [Страница с графиками](https://viktor-vk.github.io/projects/tesera-bgg/) |

## Что осознанно не включено

- Подключения к БД, хосты, имена внутренних серверов и схем - заменены функциями-заглушками с пояснением.
- Файлы с реальными данными (выгрузки, реестры точек, результаты расчётов) - не публикуются.
- Названия брендов, регионов и других идентифицирующих сущностей - обезличены.
- Из-за этого первые три проекта не выполняются "от начала до конца" сами по себе - это осознанный выбор:
  показывать подход и код, а не пытаться повторить его на чужих/отсутствующих данных. Исключения -
  `Мониторинг рынка вакансий hh.ru` и `Сравнение рейтингов Tesera и BGG`, где данные публичны и ноутбуки
  выполняются как есть.
