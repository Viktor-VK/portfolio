# Сравнение рейтингов Tesera и BoardGameGeek

**Тип проекта:** мини-исследование на открытых данных - от сбора и нормализации до статистических выводов и
интерактивной страницы.

**Страница с графиками:** https://viktor-vk.github.io/projects/tesera-bgg/

## Задача

Понять, совпадают ли вкусы российского сообщества настольщиков (Tesera.ru) с мировым (BoardGameGeek), и
проверить очевидный на первый взгляд вывод «на Tesera оценивают щедрее» на ошибку отбора.

## Главные выводы

| # | Вывод | Цифры |
|---|---|---|
| 1 | «На Tesera оценивают выше» - в основном эффект отбора | в топе Tesera разница +0,21 (p ≈ 3e-40), в топе BGG +0,01 (p = 0,4) |
| 2 | «Золотая эпоха» 2000-2014: эти игры на Tesera ценят выше, по новинкам вкусы совпадают | +0,25...+0,30 у игр 2000-2014, около 0 у игр 2020+ |
| 3 | Tesera выше ценит военные и экономические игры, ниже - компанейские | +0,23 / +0,14 / -0,10 |
| 4 | Дополнения на Tesera оценивают сдержаннее, чем базовые игры | значимо в обеих выборках |
| 5 | Игру на Tesera оценивают скорее целиком: все суб-рейтинги тесно связаны с итоговой оценкой | rho 0,78 (реализация) ... 0,90 (глубина) |

Дополнительно: какие издатели чаще всего встречаются в топах (лидер - Hobby World) и где у их изданий самый высокий
спрос на барахолке Tesera.

## Данные

- **Две выборки:** топ-500 Tesera (по байесовскому рейтингу) и топ-500 по рейтингу BGG - 756 уникальных игр,
  244 входят в оба топа. Две выборки нужны, чтобы отделить реальную разницу от эффекта отбора.
- **Tesera:** открытый API сайта (`api.tesera.ru/games` - списки и карточки игр) и HTML-страницы игр
  (суб-рейтинги, жанры, темы, теги, издатели, награды, аудитория, барахолка).
- **BoardGameGeek:** средняя оценка, geek rating и число оценок - в копии, которую Tesera хранит для каждой
  игры вместе с идентификатором BGG. Официальный XML API BGG с 2025 года требует регистрации приложения, а сайт
  закрыт антибот-защитой, поэтому BGG напрямую не парсится.

**Особенности API Tesera, найденные при сборе:** `offset` - это номер страницы, а не позиция; `limit` больше 100
молча режется; при равных рейтингах порядок между страницами плавает. Сборщик берёт страницы с запасом, убирает
дубли и пересортировывает сам.

## Структура данных

Сырые данные - «узкая» таблица: одна строка = одно значение одного измерения одной игры (~42 тыс. строк на
выборку). Так в одну схему ложатся и числа (рейтинги, счётчики), и многозначные поля (жанр -> поджанры, авторы,
награды с годом и результатом).

| Колонка | Смысл |
|---|---|
| `list_sort`, `list_rank` | из какого топа строка и позиция в нём |
| `tesera_id`, `alias`, `title`, `bgg_id`, `is_addition` | ключ игры |
| `platform` | о какой площадке значение: `tesera` / `bgg` |
| `source` | откуда взято: `tesera_api_list` / `tesera_api_game` / `tesera_html` |
| `block` -> `metric` -> `dim_l1` -> `dim_l2` -> `seq` | иерархия измерения, например `classification` -> `subgenre` -> «Война» -> «тактические» |
| `value_num` / `value_text`, `unit` | значение |

CSV в формате для Excel и Power BI с русской локалью: разделитель `;`, десятичная запятая, UTF-8 с BOM.

## Файлы

| Файл | Что делает |
|---|---|
| `collect.py` | сбор топа в узкую таблицу |
| `make_wide.py` | узкие таблицы двух выборок -> широкая, одна строка на игру |
| `01_анализ_рейтингов.ipynb` | анализ: эффект отбора, год выпуска, жанры, дополнения, суб-рейтинги, издатели |
| `analysis.py` | те же расчёты -> `results/tesera-bgg.json` для страницы на сайте |
| `csv_format.py` | единый формат CSV проекта |
| `data/` | собранные данные (срез 25.09.2026) |

Повторить с нуля:

```bash
python collect.py --limit 500 --out data/tesera_top500_long.csv
python collect.py --limit 500 --sort=-ratinggeekbgg --out data/bgg_top500_long.csv
python make_wide.py
python analysis.py
```

## Стек

Python, requests, BeautifulSoup, pandas, scipy (t-тест, U-тест Манна-Уитни, корреляция Спирмена), matplotlib;
на сайте - Astro и ECharts.

## Ограничения

- Обе выборки - топы, а не вся база: выводы про заметные игры.
- Дата синхронизации BGG-полей на Tesera неизвестна - возможен небольшой лаг.
- Жанры и издатели на Tesera заполнены не у всех игр, теги проставляют пользователи.
- Счётчики барахолки - накопленные объявления, а не текущий спрос.
- Корреляции не доказывают причин: объяснения в выводах - гипотезы.
